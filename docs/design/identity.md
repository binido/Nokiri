# Nokiri identity

The chosen mark is an N built from one fixed path with two visible endpoints.
It connects the name to deliberate routing without a shield, globe or padlock.
The warm tile uses #FFB45B, dark routing #402100, and endpoints #FFF3DF.

Explored alternatives: a returning loop (concept-b.svg) and a branching junction
(concept-c.svg). The loop suggested automatic reconnection, and the fork suggested
multipath routing; the single path better expresses Nokiri's fixed selection.
The chosen stroke-based SVG is the scalable source for future Linux exports.
The current macOS icon is a standard .icns, not an Icon Composer / Liquid Glass asset.

The logo-design skill's SVG audit and render tools were used. The icon was inspected
at 1024 px and downsampled to 16, 32 and 64 px. Small-size and full-size exports use
one consistent silhouette. This is original artwork; no trademark clearance was done.

UI tokens: surface #191714, elevated surface #26231F, primary #FFB45B,
on-primary #432300, body #F0E1D0, secondary #C1B7AA. Light mode uses #FFF8F0,
#F5EEE6, #854800, white, #271B0F and #685B4B respectively.
Roboto regular is bundled locally; all interaction icons use Material Symbols Rounded.
